La roadmap vit dans le **Kanban Notion** (base *Roadmap* sous le hub), groupée par **phase**, triée par **Ordre**. Chaque carte : Objectif / Dépend de / Périmètre / Comment / Done + un **Claude Code Prompt** prêt à coller.

- **MVP = Phases 0 → 3** (fondations, catalogue, accès/robustesse, playlist).
- Puis 4 (docs/DX), 5 (déploiement), 6 (communauté), 7 (tunes/liveries), 8 (télémétrie/leaderboards), 9 (exploratoire).

Exécution **carte par carte** dans l'ordre des codes (0.1, 0.2, …). On ne code pas hors contrat. On checkpoint l'avancement et on met le **Statut** à jour dans Notion (Backlog → A faire → En cours → Fait).
